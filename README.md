# 遊戲貨幣追蹤（貨幣帳本）

個人使用的網頁工具：記錄多個遊戲帳號每天的貨幣餘額，查看庫存變化，並比較各帳號的收益。

## 啟動

**不需要安裝任何東西。** 直接用 Chrome 或 Edge 開啟 `index.html`（雙擊即可）。

想用固定網址開啟（例如加到書籤）時，也可以在這個資料夾執行：

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

然後打開 http://localhost:5173 。

> 注意：用「雙擊 index.html」和「localhost 網址」開啟時，瀏覽器會把它們當成兩個不同網站，資料**不會共用**。請固定用其中一種方式。

## 安裝到 iPhone（免費，不需要 App Store）

這是一個「可安裝的網頁 App」（PWA）：放到網路上後，用 iPhone Safari 打開並「加入主畫面」，就會有自己的圖示，全螢幕開啟、直接進入每日錄入，沒有網路也能用。

### 第一次：放到 GitHub Pages（約 5 分鐘）

1. 到 <https://github.com> 註冊或登入。
2. 右上角 **＋ → New repository**，名稱例如 `coin-ledger`，選 **Public**，按 **Create repository**。
   （Public 只代表程式碼公開；你的記帳資料存在手機裡，不會上傳。）
3. 在新的 repository 頁面點 **uploading an existing file**，把 `coin-ledger-app.zip` 解壓縮後裡面的**所有檔案和資料夾**
   （`index.html`、`manifest.webmanifest`、`sw.js`、`css`、`js`、`icons`）一起拖進去，按 **Commit changes**。
4. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾 **/(root)**，按 **Save**。
5. 等 1～2 分鐘，頁面上方會出現網址，例如 `https://你的帳號.github.io/coin-ledger/`。

### 在 iPhone 上安裝

1. 用 **Safari**（不是 Chrome）打開上面的網址。
2. 點下方的「分享」按鈕 → **加入主畫面** → 新增。
3. 之後從桌面的「貨幣帳本」圖示打開即可。

### 之後要更新程式

把改過的檔案再上傳到同一個 repository（同名檔案會被覆蓋），並把 `sw.js` 第一行的 `VERSION` 改成新的值（例如 `v4`），手機下次連網開啟時就會換成新版。資料不受影響。

### 資料放在哪

- 手機 App 的資料存在 iPhone 裡，和電腦上的資料**各自獨立**。
- 從主畫面開啟的 App 不受 Safari「7 天沒用就清除資料」的限制，但刪掉主畫面圖示會一起刪除資料。
- 要在手機和電腦間搬資料：一邊「下載完整備份」→ 用 AirDrop／通訊軟體傳過去 →另一邊「從備份還原」。

## 功能

介面支援**淺色／深色模式**（左上角太陽／月亮切換，預設跟隨系統），以及進場、數字跑動、圖表繪出、主題圓形擴散等動畫；系統設定「減少動態效果」時會自動關閉動畫。左側選單底部的按鈕可展開顯示文字。快捷鍵 `Ctrl + K` 可直接搜尋記錄。

| 頁面 | 內容 |
|---|---|
| Stock 購入報告（Stock Acquisitions Report） | 每天新增多少 Stock：購入 = CF Bal 變化 ＋ 期間賣出去的（原本的 Stock Acquired）。六張指標卡（總購入、每日平均購入、其中出售東西所得、期末 Stock、Stock 變化、記錄完成率），可依日／週／月彙整、比較前一期、篩選帳號；購入來源圓環圖與 Stock 分布；可匯出 CSV。賣出去的明細不在這裡，避免和出售報告重複看。 |
| Stock 出售報告（Stock Sales Report） | 每一筆「出貨」就是一筆出售：日期、買家／對方、哪個帳號的 Stock、數量、金額（RM）、交易狀態（未填金額／已完成；朋友是待管理員定價／已定價／已退回）。期間（7／30／90 天、今年、全部）、帳號、狀態篩選；出售數量、金額、平均單價、未完成合計；依買家彙總；可補填買家和單價；匯出 CSV。合計不含退回的出貨。 |
| 總覽 | 右上兩個按鈕：**CF Bal**（只填 CF Bal）和**出貨**（只記出貨，可看／刪最近出貨）。Stock 庫存、昨日／近 7 日／近 30 日 Stock Acquired（附出貨量），預設分成**打 Mob** 和**賣貨**（＝「其中出售東西所得」）兩項，各自顯示合計和日均；每日 Stock 趨勢圖；各帳號 Stock Acquired（每日／累計切換）；帳號排行（總 Stock Acquired／每日平均／出貨）；Stock Acquired 為負數的記錄；今日錄入狀態。可切換 7／30／90 天或自訂期間，並篩選帳號。 |
| 每日錄入 | 一個畫面填完所有啟用帳號的 CF Bal（出貨欄顯示會算進來的出貨，可按「＋出貨」補記），即時算出 Stock Acquired，一次儲存。可切換日期補登、「沿用」上次 CF Bal、Enter 跳到下一個帳號。 |
| 記錄 | 可搜尋、依帳號／日期篩選、只看 Stock Acquired 負數；可依記錄日、帳號、CF Bal、Stock 變化、出貨、Stock Acquired、Stock Acquired 日排序；編輯、刪除（需確認）；匯出／匯入 CSV。 |
| 帳號 | 新增、編輯、停用／啟用、刪除（有記錄時會建議改為停用）。卡片或列表檢視，含 Stock、最近記錄、近 30 日 Stock Acquired 與走勢線。 |
| 結算 | 管理員：每位朋友的出貨總金額、已付、還欠多少、待定價筆數；點進去逐筆或一次定價（每 1B 多少 RM）、記付款、看他的帳本。朋友：自己的出貨、單價與金額、收到的付款、還欠多少。 |

## 多人使用與結算

- **管理員**是 jackhao067@gmail.com（程式裡只放信箱的雜湊值）。
- **加朋友**：管理員在「設定 → 使用者」輸入朋友的 Gmail，再到 Google Cloud → Google Auth Platform → 目標對象 → **測試使用者** 加上同一個 Gmail。朋友打開網址用 Google 登入即可，不用設定任何東西。
- **每個人有自己的帳本**（帳號、CF Bal、出貨、Stock Acquired），互相看不到；管理員可以在「使用者」或「結算」按「看帳本」切換去看（只能看，不能改），按「回到我的帳本」回來。
- **結算流程**：朋友按「出貨」記一筆 → 出現在管理員的「結算」，標示「待定價」（側欄有數字提醒）→ 管理員填單價（每 1B 多少 RM），金額 = 數量 ÷ 1B × 單價，算進管理員欠朋友的錢 → 管理員付錢後「記一筆付款」→ 雙方都看到總金額、已付、還欠多少。
- 已經定價的出貨，朋友不能自己刪除；要改的話管理員先「取消定價」。
- **退回記錯的出貨**：管理員在「結算」那筆旁邊按 ⊘，選理由（重複記錄、數量記錯、帳號選錯…）並可寫說明 → 這筆立刻不算錢；朋友下次打開 App 時自動撤回，他的 Stock Acquired 和出貨合計扣掉那筆數量，並看到退回理由。按「復原」可以取消退回。Stock 是遊戲裡的 CF Bal，本來就不受出貨記錄影響。
- **結算調整（Settlement-only adjustment，不影響 Stock）**：管理員在朋友的結算頁按「新增調整」，填金額（加到欠款或從欠款扣掉）和必填原因 → 狀態「待對方批准」，**不算進結算** → 朋友在通知或結算頁按「批准」或「拒絕」→ 批准後才算進欠款。不會改任何人的 Stock、出貨或帳本，也不是買入、賣出或 Stock 轉移。每筆保留調整前後金額、原因、發起人、受影響的人、批准人、狀態和時間；管理員可撤回還沒被處理的調整。同一筆不會被重複送出或重複批准。
- **通知**：右上角鈴鐺。管理員看到朋友提交的出貨（待定價）和朋友對調整的批准／拒絕；朋友看到要他批准的調整、被定價／退回的出貨、被撤回的調整。有要你處理的事項時，鈴鐺有數字、每頁上方有黃色提示。每個人只看得到自己權限內的資料算出來的通知。
- 只有用「出貨」按鈕記的出貨會算進結算；記錄裡的「補記出貨」欄位不算。
- 移除使用者只會取消登入權限，他的帳本和結算紀錄會保留。

右上角「新增記錄」可隨時新增單筆；同帳號同一天已有記錄時會提示並改為更新，不會產生重複。「儲存並下一個帳號」可連續輸入。

## 計算規則

- **CF Bal = Stock（庫存）**：每天輸入每個帳號當下的餘額。總 Stock = 各帳號最近一次 CF Bal 加總。
- **出貨**：每次出貨另外記一筆（日期、帳號、數量）。出貨會讓 Stock 變少，但**不扣 Stock Acquired**。
  預設（Stock Acquired 算前一天）時，今天出的貨會在明天記 CF Bal 時加回今天的 Stock Acquired；還沒有下一次 CF Bal 的出貨會標「待算進 Stock Acquired」。
- **Stock 變化** = 這次 CF Bal − 上次 CF Bal（第一筆沒有）。
- **Stock Acquired（賺到的）** = Stock 變化 ＋ 出貨。預設算在記錄日的**前一天**（今天記的 = 昨天賺的），可在設定改成記錄當天。
  例：昨天 CF Bal 100,000，今天 CF Bal 90,000、出貨 30,000 → 昨天 Stock Acquired = 20,000，Stock = 90,000。
- **跨 N 天**：和上次記錄相隔多天時，Stock Acquired 是這幾天的合計；沒記錄的日子不當成 0。
- **Stock Acquired 負數**：CF Bal 少掉的比出貨還多（通常是出貨忘了填），會標示讓你檢查，系統不會修改你的輸入。
- **每日平均** = 期間 Stock Acquired ÷ 涵蓋天數（適合比較記錄天數不同的帳號）。
- **出售東西所得**：記 CF Bal 時可選填「其中出售東西所得」，標示這次增加的部分有多少是賣東西換來的。只是標示來源，不改變 CF Bal、Stock、Stock Acquired 或任何出貨；在購入報告和記錄頁顯示。
- **角色提醒**：每個帳號可以追蹤 **Artificial Boost - Mesos Drop Rate**（每 30 天續期，剩 3 天內提醒）和 **Maple Union Coin**（每 3 天領一次，可以領時提醒）。記 CF Bal（或每日錄入、新增記錄）時勾選「今天續期了／今天領了」，也可以在帳號卡片上直接按「已續期／已領」。到期或可以領的項目會出現在總覽上方，帳號分頁會顯示數字。帳號設定裡可以關掉不需要的提醒。
- **職業與頭像**：帳號可以選 MapleStory SEA 的職業（依 Explorers、Cygnus、Heroes、Resistance、Nova、Sengoku、Flora、Anima、其他分組），會顯示自己畫的職業徽章（小圖示）和五大職業的 Q 版角色（帳號卡片上，站在平台上像遊戲裡一樣；都是原創圖，不是官方圖）。上傳圖片時可以在圖上拖曳框出角色，並把單色背景去掉。也可以上傳自己角色的遊戲截圖（去背 PNG 最好看），會保留整個角色、站在小平台上像遊戲裡一樣呈現；圖片只存在自己的帳本（跟著雲端同步），不放進 GitHub。
- **大數字**：1 億起顯示成 `100M`，10 億起顯示成 `1B`（輸入框仍顯示完整數字）。輸入時也可以打 `20k`、`100m`、`1.5b`。

## 資料儲存

- 每台裝置先存在瀏覽器的 `localStorage`（鍵名 `gct:data:v1`），沒網路也能記。
- 在正式網址登入後，會自動同步到 Firebase 雲端資料庫（專案 `coin-ledger-512414`，新加坡）：
  - `ledgers/{email}`：設定、帳號；`ledgers/{email}/parts/{年份}`：那一年的記錄和出貨。
  - `allow/{email}`：允許登入的名單；`settle/{email}`：單價、付款、退回的出貨、結算調整；`resp/{email}`：本人對結算調整的批准／拒絕（只有本人能寫）。
  - 誰能讀寫由 Firebase 安全規則決定，規則內容在 `firestore.rules`（只貼在 Firebase 控制台，**不用上傳到 GitHub**）。
- 同一台裝置換別的 Gmail 登入時，上一個人的本機資料會另外收好（`gct:data:user:<email>`），不會混進新帳號。
- 舊版存在 Google 雲端硬碟的資料不會被刪除；升級後第一次同步會把本機資料搬到 Firebase。
- 還原備份、清除資料前，會先把目前資料暫存在 `gct:data:before-restore`，可在設定頁復原一次。
- 讀取資料失敗時，原始內容會另存為 `gct:data:corrupt:<時間>`，不會被覆蓋。
- **請定期在「設定與備份」下載 JSON 備份**；超過 7 天未備份時，總覽與側欄會提醒。

### CSV 格式

```
date,account,game_id,cf_bal,shipped,note
2026-10-22,主帳號,TW-100231,12345,3000,備註
```

- 必填：`date`、`cf_bal`，以及 `account` 或 `game_id` 其中一個（先用遊戲內 ID 對應，再用名稱）。
- 也接受中文欄位名（日期、帳號、遊戲ID、餘額／庫存、出貨、備註）與 `2026/10/22` 日期寫法。
- `shipped` 是直接記在那筆記錄上的出貨；用「出貨」按鈕記的出貨存在備份檔（JSON）裡，CSV 匯出時另外列在 `shipped_total`（合計）。
- 匯出檔多出的 `shipped_total`、`stock_change`、`stock_acquired`、`acquired_date`、`from_sales` 是計算結果（舊版的 `sales`、`sales_date` 也一樣），匯入時會自動忽略。
- 匯入前會顯示預覽：可新增、與現有記錄重複（可選略過或覆蓋）、錯誤列與原因、需要新建的帳號。
- 檔案須為 UTF-8（Excel 請用「CSV UTF-8」另存）。

## 目前限制

- 雲端同步、多人和結算只在正式網址（jack061800.github.io）登入後才會啟用；本機開啟時資料只在這個瀏覽器。
- 看朋友的帳本、定價、記付款都需要網路。
- 離線快取只在網址是 https（或 localhost）時啟用；直接雙擊 `index.html` 開啟時沒有離線快取，但本來就不需要網路。
- 同一個瀏覽器開多個分頁時會互相同步，但不建議在兩個分頁同時編輯同一天的資料。
- 只支援一種貨幣（名稱可改）；金額為非負整數。
- 字體（Urbanist、Noto Sans TC）從 Google Fonts 載入；離線時會改用系統字體，功能不受影響。
- 主題切換的圓形擴散效果需要 Chrome / Edge 111 以上，其他瀏覽器會直接切換。
- 總覽的各帳號 Stock Acquired 圖一次最多顯示 8 個帳號（其餘可用篩選查看）。
